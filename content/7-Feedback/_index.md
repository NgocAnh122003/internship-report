Through the meaningful **First Cloud AI Journey** internship program from **August 1, 2026** to **September 27, 2026**, I would like to share my personal feedback and contributions below to help improve the program for future cohorts:

### General Evaluation of the Program

**1. Learning and Working Environment**  
The program was organized very professionally and methodically. The learning guide materials were clear, and the detailed roadmap helped interns easily track their personal progress week by week. The combination of self-study and workshops maximized flexibility.

**2. Support from Mentors & Admin Team**  
The mentors were extremely experienced and enthusiastic. Whenever I faced difficulties configuring Lambda functions, connecting API Gateways, or troubleshooting CI/CD pipelines with GitHub Actions, the mentors always guided me through the logical process of checking system logs rather than just giving away direct answers, which significantly improved my problem-solving skills. The Admin team also provided technical support and provisioned AWS practice accounts very promptly.

**3. Relevance to Major**  
As a student from **Hanoi University of Civil Engineering (HUCE)**, I found the practical exercises closely aligned with modern cloud computing realities. Hands-on experience in building a 3-tier Serverless application (S3, API Gateway, Lambda, DynamoDB), combined with establishing security based on the Least Privilege principle using IAM and automating via GitOps CI/CD, helped me deeply understand how to operate cloud-native systems.

**4. Learning Opportunities & Skill Development**  
The program was a great opportunity for me to access advanced cloud technologies such as Serverless architecture, GitOps CI/CD automation, and standardized technical documentation building on Hugo. Besides professional skills, I also significantly improved my time management and bilingual technical report writing skills.

**5. Culture & Team Spirit**  
The knowledge-sharing culture within the program was vibrant. Everyone was open-minded, unafraid to ask questions, and actively supported each other in overcoming challenging labs and capstone projects.

---

### Survey Response

- **What were you most satisfied with during your internship?**  
  Being able to independently deploy a complete end-to-end project from infrastructure architecture to CI/CD automation on a real AWS account, turning theoretical knowledge into a running product.
- **What do you think the program needs to improve for future cohorts?**  
  Adding some recurring weekly small-group study check-in sessions so interns can interact directly and share common configuration errors.
- **Would you recommend this program to your friends?**  
  Definitely. This is the most structured cloud practice program that helps students bridge the gap between academia and industry.
