### Mục tiêu Tuần 8:

- Hoàn thiện thiết kế và triển khai dự án cuối khóa (capstone project) kiến trúc 3-Tier Serverless trên AWS.
- Tích hợp luồng tự động hóa GitOps CI/CD sử dụng GitHub Actions để triển khai Frontend.
- Áp dụng các tiêu chuẩn thực hành bảo mật tốt nhất với AWS IAM (Nguyên tắc quyền tối thiểu) cho GitHub Secrets và quyền thực thi của Lambda.
- Triển khai và kiểm thử luồng dữ liệu của các thành phần Backend Serverless (Amazon API Gateway, AWS Lambda, Amazon DynamoDB).
- Đăng tải bài blog chia sẻ kỹ thuật và hoàn thiện tài liệu báo cáo thực tập trên nền tảng Hugo.

- Thiết kế và tích hợp thành công sơ đồ kiến trúc 3-Tier Serverless hoàn chỉnh, sẵn sàng cho môi trường thực tế (production-ready).

- Xây dựng hệ thống Backend phi máy chủ tối ưu chi phí và có khả năng tự động co giãn cao với API Gateway, Lambda và DynamoDB.
- Đăng tải thành công bài chia sẻ kỹ thuật thực tế về AWS Lambda và hoàn thiện toàn diện bộ tài liệu báo cáo thực tập trên Hugo.
